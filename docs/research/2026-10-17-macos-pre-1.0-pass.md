# macOS pre-1.0 pass (2026-10-17)

The first time kubeNimbus has been run on a Mac. Machine: Apple Silicon, macOS 27.0.1, .NET SDK 10.0.301,
commit `7bac123`, which turned out to be about 140 commits behind `main`; the four blockers were
then re-checked on a NativeAOT build of `ce7638a` (the `main` of the same day), and the notes below say
where `main` had already moved on. The app was published with NativeAOT for `osx-arm64`, packaged with
`scripts/macos/build-app-bundle.sh` into a `.app` and a `.dmg`, launched through LaunchServices (`open`)
on an isolated profile (`KUBENIMBUS_PROFILE_DIR`), and driven against the k3s sandbox with real
keystrokes and real mouse events (CGEvent). The yardstick is pgNimbus on the same machine.

Every finding is marked **V** (seen on the running app) or **C** (read from the code, not exercised).

## What works

- Build: 0 warnings. Tests: Core 705 passed / 1 skipped against the live sandbox, App 444 passed.
- NativeAOT publish for osx-arm64: only the two known DataGrid warnings (IL2104/IL3053). Binary 50 MB,
  `.dmg` 30 MB. `--smoke-test` passes: about 230 ms to first frame warm, 968 ms on the very first
  (cold) launch. `--smoke-test=unreachable-cluster` passes.
- The ad-hoc signed bundle launches from LaunchServices; the Dock icon, app name and menu-bar title
  are kubeNimbus.
- V: Applications mode (health, reasons, the crash-loop page with findings, timeline and last-run
  logs); Resources mode with live watch, metrics and sparklines; previous logs (P); exec (S) with
  UTF-8 output, ANSI colour and ^C; YAML editor (E); command palette (⌘K, `logs` rows); cheat sheet
  (F1); Preferences (⌘,); Resources/Applications (⇧⌘R / ⇧⌘A); full screen from the View menu
  (the traffic-light reserve goes away correctly); "Open a terminal on this cluster" opens
  Terminal.app with the right `KUBECONFIG` and context; the native open panel; the no-kubeconfig
  empty state; ⌘Q quits cleanly with streams open (two runs, no crash report — pgNimbus's SIGABRT on
  quit did not reproduce here, though `MacShutdown` is still worth porting as insurance).

## Blockers for 1.0

1. **V — ⌘↑ / ⌘↓ / ⌘→ in the YAML editor *select* instead of moving the caret.** ⌘↑ selects to the
   start of the document, ⌘→ selects to the end of the document. The next keystroke replaces the
   selection, so one ⌘↓ followed by a letter replaced a 251-line Pod manifest with a single line —
   in the pane whose Apply button writes to the cluster. On a Mac these keys mean "go to start/end of
   document / end of line", so this is the gesture a Mac user will press. pgNimbus fixes the same
   AvaloniaEdit defaults in `Platform/MacTextKeys.cs` (with `MacTextKeysTests`); port it. The apply
   preview (server-side dry-run diff) is what stands between this and a damaged object.
2. **Fixed on `main` before this pass was written** (JetBrains Mono behind the shared font tokens,
   `e3b8473`). On `7bac123`: **V — logs, YAML, the exec terminal and every other code surface draw in a
   proportional font.**
   About 70 `FontFamily="Cascadia Mono,Consolas,monospace"` sites; a Mac has neither face and the
   generic `monospace` does not resolve, so `ls -la` columns do not line up and `|` reads as `l`.
   pgNimbus bundles JetBrains Mono NL behind a `MonoFont` token (`Fonts/NimbusFonts.cs` in its newer
   nimbusUi). Pull nimbusUi and replace the literals with the token.
3. **V — ⌘W, ⌘M and ⌘T do nothing.** There is no Window menu (Minimize, Zoom, Bring All to Front),
   no chord on Close cluster tab or New cluster tab. These are the first three keys a Mac user tries.
4. **V — The app menu is Avalonia's default, not ours.** It reads "About Avalonia", has no About
   kubeNimbus and no Settings… item, Quit is a bare "Quit", and Hide Others is bound one modifier
   away from Quit (⌥⌘Q). `MacMenu.Attach` does call `NativeMenu.SetMenu(app, …)` with About and
   Preferences, and none of it reaches the menu bar — most likely because it runs from the window,
   after Avalonia has already exported the application menu (not confirmed). pgNimbus declares the app menu in
   `App.axaml` and repairs the standard block in `Windowing/MacAppMenu.cs`.

Blockers 1, 3 and 4 and the missing Edit menu (5) were confirmed still present on `ce7638a` and are
being fixed in one bundle PR together with a nimbusUi sync.

## Should fix

5. **V — No Edit menu.** ⌘C/⌘V work only because no menu item claims them. A Mac app without
   Edit → Undo/Cut/Copy/Paste/Select All/Find also loses Emoji & Symbols and Dictation. Port
   pgNimbus's `MacMenus` + `EditCommands` together: an Edit menu *without* focus routing breaks copy
   and paste everywhere, because AppKit takes the key equivalent first.
6. **V — Shortcut labels are spelled "Cmd+K", "Cmd Shift N", "Ctrl Z".** macOS spells ⌘K, ⇧⌘N, ⌃Z.
   pgNimbus's `ChordScheme.Cmd` renders Apple's glyphs in ⌃⌥⇧⌘ order everywhere (pill, palette,
   sheet, tooltips, menus). C: `Nimbus.Ui.Hotkeys.Describe` also drops Shift and Alt.
7. **V — Menu labels are sentence-case catalog titles** ("Open the command palette", "Show or hide
   the resource sidebar", "Toggle light/dark theme"). Menus on a Mac are short Title Case verbs
   ("Command Palette…", "Hide Sidebar"). pgNimbus has a menu-title field for this (DESIGN.md rule 18).
8. **C — Window size and position are not remembered.** Every launch opens 1280×800 at the default
   spot; `workspace.json` holds no placement. Port `WindowPlacementPersistence`.
9. **Already on `main`** (`MacTrafficLights` is attached by `NimbusWindowChrome`). On `7bac123`:
   **C — traffic lights sit about 5 pt above the command bar's centre line.** Fixed by pulling
   nimbusUi (`Chrome/MacTrafficLights.cs`); it also brings the 13 px density, `FocusRing` and the
   Apple-style `ToggleSwitch`.
10. **V — The interface font is Inter, not San Francisco.** pgNimbus requests "System Font" on macOS
    (and corrects letter spacing). Owner's call, but it is the largest single "this is not a Mac app"
    signal after the menu.
11. **V — Full screen leaves an empty black band (~36 px) above the command bar.**
12. **C — Delete on the list is bound to the Delete key**, which a Mac keyboard only produces as
    fn+⌫. The Mac gesture is ⌘⌫. Add it as the macOS synonym (still arming the confirm strip).
13. **C — F1 is the only route to the cheat sheet.** F1 needs fn on a Mac; pgNimbus adds ⌘?. There is
    also no previous/next cluster-tab chord (⇧⌘[ / ⇧⌘]); the app page's "‹ Applications" has no ⌘[.
14. **C — The exec pane's copy/paste is ⇧⌃C / ⇧⌃V only.** Terminal.app and iTerm use ⌘C/⌘V, which
    do not collide with ^C on a Mac. Add them as the macOS chords.
15. **V — The open panel starts in Documents and hides dot-folders**, so `~/.kube` cannot be reached
    without knowing ⇧⌘. . Start it in `~/.kube` when that exists. It is also a free-standing panel,
    not a sheet on the window.
16. **C — Secrets go to the clipboard as plain text.** pgNimbus marks them
    `org.nspasteboard.ConcealedType`/`TransientType` and clears them after 30 s (`SecretClipboard`).
17. **C — `LSMinimumSystemVersion` is 11.0**, but a .NET 10 NativeAOT binary's `minos` is 12; on
    macOS 11 the app dies in dyld instead of saying it needs macOS 12. pgNimbus raised it to 12.0 and
    added a `minos` check to `release.yml`.
18. **C — Finder-launched exec plugins:** the login-shell PATH list lacks the Google Cloud SDK `bin`
    (where `gke-gcloud-auth-plugin` lives), asdf/mise shims, nix profiles, `~/.rd/bin`, `~/.krew/bin`;
    and only PATH is repaired, so `AWS_PROFILE`-style exports from a shell rc never arrive. Not
    exercised (the sandbox uses client certificates).
19. **C — The confirm strip puts Confirm before Cancel** (Windows order); DESIGN.md rule 16 says Mac
    order, primary last, on every platform.

## Nice to have

- V: YAML undo is per keystroke (pgNimbus groups by word: `EditorTypingUndo`).
- V: "Previous" on a container that never restarted shows the raw API text
  `previous terminated container "app" … not found (400 Bad Request)`; say it in words.
- V: the YAML highlighter colours digit runs inside a plain scalar (the pod UID).
- V: the list reorders under the pointer when CronJob pods come and go; a click can land on the row
  that just moved into place. Not Mac-specific.
- V: the ANSI red in the exec pane is too dark on the dark theme.
- C: Help menu with one item — AppKit adds a search field to any menu named Help; pgNimbus moved
  Keyboard Shortcuts into View for that reason. View offers only a light/dark toggle, so the menu
  cannot return to "follow the system".
- C: the ☰ menu stays on macOS, duplicating the app menu (pgNimbus hides it there).
- C: hardened runtime + entitlements for the ad-hoc signature (pgNimbus has them); Developer ID
  signing and notarization remain the shared gap if 1.0 must open without a Gatekeeper warning.
- C: `.pdb` files ship inside `Contents/MacOS`; add `LSApplicationCategoryType`
  (`public.app-category.developer-tools`).
- V (owner): the exec pane's shell-picker placeholder "auto (bash/sh/ash)" is not vertically centred.
- V (`ce7638a`): ⇧⌘R did not switch from Applications to Resources once in two tries on a fresh launch,
  where it had on `7bac123`; not reproduced reliably, worth a second look.
- V: the "Open a terminal" `.command` overlays are written under `~/Library/Application Support`
  even with `KUBENIMBUS_PROFILE_DIR` set.

## Found in the tooling (fixed in this pass)

- `scripts/sandbox-up.sh` renamed the context with GNU-only `\b` in `sed`, so on macOS the context
  stayed `default`; it now uses a portable expression.
- Its `kube` helper ran `docker exec` without `-i`, so the Helm release seeding piped nothing
  ("error: no objects passed to apply") on every platform.
- `sandbox-up.sh` / `sandbox-down.sh` were committed without the executable bit.
- Both sandbox scripts told the reader to run `dotnet test <csproj>` positionally, which CLAUDE.md
  documents as running nothing; they now point at `scripts/test.sh` / `test.ps1`.
