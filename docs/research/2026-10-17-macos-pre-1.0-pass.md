# macOS pre-1.0 pass (2026-10-17)

The first time kubeNimbus has been run on a Mac. Machine: Apple Silicon (Mac15,12), macOS 27.0.1,
.NET SDK 10.0.301. The yardstick is pgNimbus on the same machine.

## How this was run, and why it was run twice

The first pass was made on a checkout about 140 commits behind `main` and was driven with System
Events keystrokes. Both made it unreliable: several findings were already fixed on `main`, and System
Events delivers every ⌘ chord to Avalonia with an extra ⌘A in front, which produced findings that were
not real ("⌘↑ selects to the start of the document", "⌘V replaces the field", "⌘Q does not quit").

This page records the **second** pass, which replaces the first:

- Code: `main` at `d13db7a` plus PR #396 (`fix/macos-native-blockers`, `c1bcf5c`), which fixes the
  blockers the first pass found. Where a result differs between the two, it says so.
- Build: NativeAOT `osx-arm64`, packaged with `scripts/macos/build-app-bundle.sh` into a `.app` and
  `.dmg`, the `.app` copied out of the mounted image and launched through LaunchServices
  (`open -n … --env KUBENIMBUS_PROFILE_DIR=<fresh dir> --env KUBECONFIG=<sandbox>`).
- Input: **real HID events** posted with CGEvent (keyboard and mouse), never System Events
  keystrokes. Text was entered by pasting, because synthetic key codes follow the active keyboard
  layout (a Russian layout typed `скфырдщщз` for "crashloop").
- Cluster: the k3s sandbox from `scripts/sandbox-up.sh`.

Every finding is marked **V** (seen on the running app) or **C** (read from the code, not exercised).

## Automated checks

- Tests on `main`: Core 1076 passed / 12 skipped against the live sandbox (9 need Argo's controller,
  3 need cert-manager), App 791 passed. One Core test failed only on macOS — a CA bundle with a broken
  block surfaced Apple's `Unknown format in import` instead of naming the kubeconfig field — fixed in
  #393. PR #396's branch: Core 1076 / 12 skipped, App 834.
- NativeAOT publish: only the two known DataGrid warnings. `--smoke-test` and
  `--smoke-test=unreachable-cluster` exit 0 (about 230 ms to first frame warm on the published binary,
  786 ms on a first, cold launch of a new build).
- On `main` one smoke run whose platform failed to start ("Avalonia.Native was not able to start the
  RenderTimer. Native error code is: -6661", transient) **died with SIGABRT** on the way out:
  `exit()` ran libAvaloniaNative's static destructors, which called back into the stopped .NET
  runtime. macOS showed the "kubeNimbus quit unexpectedly" dialog. The same path exists on a normal
  quit. PR #396 ends the process with `_exit` on macOS; with it, ⌘Q quit cleanly every time and no
  crash report appeared.

## What works (V, PR #396 build)

- **Menu bar.** kubeNimbus menu: About kubeNimbus, Settings… ⌘,, Services, Hide ⌘H, Hide Others ⌥⌘H,
  Show All, Quit kubeNimbus ⌘Q. Cluster (New cluster tab ⌘T, Switch cluster… ⌘P, Close cluster tab ⌘W),
  Edit (Undo, Redo, Cut, Copy, Paste, Select All, Find…, plus macOS's own Writing Tools, AutoFill,
  Dictation, Emoji & Symbols), View, Window (Minimize ⌘M, Zoom, Bring All to Front), Help. On `main`
  the app menu is still Avalonia's ("About Avalonia", bare "Quit", Hide Others on ⌥⌘Q) and there is no
  Edit or Window menu.
- **Window and keys.** ⌘M minimizes, ⌘W closes the cluster tab in front, ⌘T opens the switcher with
  focus in its search box, ⌘1/⌘2 switch tabs, ⌘K palette, ⌘, Settings, ⇧⌘A / ⇧⌘R switch modes, ⌘F
  focuses the list search, Esc dismisses the confirm strip and overlays.
- **Applications mode.** The list with health, reasons and Argo sync; the crash-loop and never-ready
  pages with findings, quoted evidence, timeline and merged logs.
- **Resources mode.** Live watch, CPU/memory with sparklines, list search with the empty state, P on a
  crash-looping pod loads the previous run, L / Shift+L logs (Shift+L opens maximized), F
  port-forward (`redis-cli PING` through it answered `+PONG`), S exec, E YAML.
- **Exec.** JetBrains Mono, columns line up, UTF-8 out (`Über ✓`), ⌘V pastes into the shell, ⌘A ⌘C
  copies the screen with UTF-8 intact, ^C interrupts `sleep 30`.
- **YAML editor.** With #396, ⌘↑ / ⌘→ / ⌘↓ move the caret (document start, line end, document end)
  without selecting. Review… → server-side dry-run diff → Apply changes: the label reached the cluster.
- **Mutations through the confirm strip.** Scale (strip, then "Scaled to 3"), rollout restart
  (`restartedAt` stamped on the template), delete (Delete key arms it, Esc cancels, Delete confirms,
  the pod is gone).
- **Everything else visited:** namespace picker (⇧⌘N with a row focused), Nodes with the summary bar and
  node detail, Helm releases and a release's values, Argo CD dashboard, Access review, Events list,
  Preferences (General and Appearance; Theme switches to Light immediately and persists), the demo
  cluster with its banner, "Open a terminal on this cluster" (Terminal.app opens with `KUBECONFIG`
  set to the overlay plus the sandbox file, `kubectl` reaches the cluster), quit and relaunch restores
  the tab, the mode and the kind.

## Still to fix

Blockers are gone with #396. What is left, most important first:

1. **V — The palette ranks a description match above an exact title match, and Enter runs it.**
   Typing "Nodes" or "Services" puts "Advanced view: show only everyday kinds" first (its subtitle
   lists "Pods, Deployments, Services, Nodes…"), above the Nodes / Services kinds, so Enter turns the
   Advanced view off instead of opening the kind. It happened twice in this pass by accident. Not
   macOS-specific.
2. **V — ⌘⌫ does nothing on a selected row.** Delete is bound to the Delete key, which a Mac keyboard
   only produces as fn+⌫. Finder's and Mail's gesture is ⌘⌫; add it as the macOS chord (still arming
   the confirm strip).
3. **V — No back gesture on the application page.** ⌘[ does nothing; only Esc and the
   "‹ Applications" link go back. Every Mac app with back navigation uses ⌘[.
4. **V — Shortcut labels are spelled "Cmd+K", "Cmd+1…9", "(Cmd+S)".** macOS spells ⌘K, ⌘1…9. C:
   pgNimbus's `ChordScheme.Cmd` renders Apple's glyphs everywhere; `Nimbus.Ui.Hotkeys.Describe` also
   drops Shift and Alt.
5. **V — Menu items are sentence-case catalog titles** ("Open the command palette", "Show or hide the
   resource sidebar", "Toggle light/dark theme", "New cluster tab"). Mac menus are short Title Case
   ("Command Palette…", "Hide Sidebar", "New Tab").
6. **V — The "Review…" button draws its ellipsis as two dots** ("Review..") in the primary button's
   semibold face. The string is the `…` character, so it is the font or the trimming, not the text.
7. **V — Text clipped at the right edge:** the node Overview's "limits 48.79 GiB (630%" loses its
   closing parenthesis, and the app page's Restart tooltip runs off the window edge.
8. **V — "Previous" on a container that never restarted shows the raw API error**
   (`previous terminated container "app" in pod … not found (400 Bad Request)`). Say it in words.
9. **C — Window size and position are not remembered** (every launch is 1280×800 at the same spot).
   pgNimbus has `WindowPlacementPersistence`.
10. **C — `LSMinimumSystemVersion` is 11.0** but a .NET 10 NativeAOT binary's `minos` is 12, so a
    macOS 11 Mac fails in dyld instead of saying it needs macOS 12. pgNimbus raised it to 12.0 and
    checks `minos` in `release.yml`.
11. **C — Secrets go to the clipboard as plain text.** pgNimbus marks them
    `org.nspasteboard.ConcealedType` and clears them after 30 s.
12. **C — Exec plugins from a Finder launch:** the PATH repair lacks the Google Cloud SDK `bin`
    (`gke-gcloud-auth-plugin`), asdf/mise shims, nix profiles, `~/.rd/bin` and `~/.krew/bin`, and only
    PATH is repaired (shell-rc exports such as `AWS_PROFILE` never arrive). Not exercised: the sandbox
    uses client certificates.
13. **C — Confirm strips put the primary button before Cancel** (Windows order); nimbusUi's DESIGN.md
    rule 16 says primary last on every platform. The YAML preview's "Apply changes / Cancel" does the
    same.
14. **V — ⇧⌘N did nothing twice right after a confirm strip had been closed**, and opened the picker
    once a row was clicked. The shortcut is handled by the list view's own key handler, not a window
    binding, so it needs focus inside the list; not investigated further.
15. **V — While the window is minimized the menu bar shows only the app menu** (Avalonia's per-window
    menu); the Dock icon restores it.

## Nice to have

- C: the interface font is San Francisco by default now ("System"), with Inter as a choice — this is in
  `main` and settled the biggest "not a Mac app" signal the first pass named.
- C: hardened runtime and entitlements for the ad-hoc signature (pgNimbus has both); Developer ID
  signing and notarization remain the shared gap if 1.0 must open without a Gatekeeper warning.
- C: `.pdb` files ship inside `Contents/MacOS`; `LSApplicationCategoryType`
  (`public.app-category.developer-tools`) is missing from the plist.
- C: a "Help" menu with one item gets AppKit's search field; pgNimbus moved Keyboard Shortcuts into
  View for that reason. The ☰ menu stays on macOS, duplicating the menu bar.

## Tooling found on the way (fixed in #392)

`scripts/sandbox-up.sh` renamed the context with GNU-only `\b` in `sed` (so on macOS the context stayed
`default`), and its `kube` helper ran `docker exec` without `-i`, so the Helm release seeding piped
nothing on every platform. The `.sh` scripts lacked the executable bit, and both sandbox scripts
suggested a `dotnet test` invocation that runs nothing.
